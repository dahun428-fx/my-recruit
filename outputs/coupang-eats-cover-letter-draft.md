# 정다훈 자기소개서 (쿠팡이츠 웹 플랫폼 · Staff-level Frontend Engineer 지원용)

## 웹 아키텍처·성능·팀 생산성을 함께 끌어올리는 프론트엔드 엔지니어

저는 React·Next.js·Vue 3·TypeScript 기반으로 PC·모바일 웹을 설계·개발해 온 프론트엔드 엔지니어입니다. 총 경력은 5년 9개월이지만, 그 시간을 화면 구현에만 쓰지 않고 웹 아키텍처 설계, 렌더링·성능 개선, 그리고 팀 전체의 개발 생산성과 품질 기준을 세우는 일에 집중해 왔습니다. 레거시 커머스를 Next.js 구조로 전환하며 SSR·CSR을 나눠 성능과 SEO를 잡았고, 고객사·서비스가 늘어나는 환경에서는 컴포넌트화·모듈화로 반복 개발을 줄이는 구조를 직접 설계했습니다. 쿠팡이츠 웹 플랫폼이 요구하는 유연한 PC·모바일 웹 아키텍처와 성능·생산성 향상이, 제가 지난 몇 년간 실제로 해결해 온 문제와 맞닿아 있다고 판단해 지원했습니다.

## Next.js 전환과 Config-Driven UI로 웹 아키텍처를 설계하다

웹 아키텍처를 다룬 대표 경험은 한국미스미 글로벌 B2B 커머스입니다(소속: 내담씨앤씨 SI 프로젝트). PHP·jQuery 기반 레거시는 페이지마다 렌더링 방식이 제각각이라 유지보수성과 성능·SEO를 함께 잡기 어려웠습니다. 저는 이 서비스를 Next.js·React·TypeScript 구조로 전환하면서 페이지 성격에 따라 SSR과 CSR을 나누고, Lazy Loading·비동기 API·폰트 최적화를 적용했습니다. 그 결과 페이지 접근 시간을 8초에서 2초로 단축했고, Next.js 전환 후 기존 PHP 서비스 대비 평균 로딩 속도도 개선했습니다.

이후 대웅제약 AI추진팀에서는 서비스와 고객사가 늘면서 화면·문구·테마·기능 노출 조건이 제각각 달라지는 문제를 만났습니다. 고객사마다 개별 개발하면 구축 기간과 품질 편차가 커진다고 판단해, 공통 화면과 컴포넌트를 Base-Theme으로 분리하고 고객사별 차이는 Config-Driven UI로 관리하는 구조를 설계했습니다. Storybook 중심으로 컴포넌트 상태별 개발·검증 절차를 세워 재사용 가능한 공통 컴포넌트를 정착시켰습니다. 이렇게 컴포넌트화·모듈화로 정리한 구조 덕분에 신규 AI 챗봇 구축 기간을 기존 10주에서 약 2주 수준으로 줄일 수 있는 공통 컴포넌트 구조를 설계했습니다.

## PC·모바일 웹 성능과 반복 개발 생산성을 함께 개선하다

성능은 웹 화면 종류를 가리지 않고 다뤄 왔습니다. 삼성물산 데이터·모바일 서비스(소속: 내담씨앤씨 SI 프로젝트)에서는 대용량 테이블·시계열 데이터를 렌더링하는 대시보드가 사용자 대기를 만들었고, 저는 렌더링 생명주기를 분리하고 Lazy Rendering을 적용해 대시보드 렌더링 시간을 2.5초에서 1초대로 개선했습니다. 같은 프로젝트의 React Native 앱에서는 검색 흐름을 정리해 검색 응답 시간을 5초에서 1초로 단축했고, AI 건강검진 챗봇에서는 초기 서비스 진입 시간을 30초에서 6초로, 답변 출력 시간을 10초에서 4초로 줄였습니다.

생산성 쪽에서는 반복 UI 개발과 배포 전후 확인이 병목이 되던 상황을 개선했습니다. Storybook 기반 컴포넌트 개발·검증 절차를 세워 반복 컴포넌트 개발 시간을 90분에서 15분으로 단축했고, Playwright로 주요 사용자 흐름과 회귀 시나리오 600여 건을 자동화했습니다. Jenkins·GitLab CI/CD 파이프라인을 정비해 배포 리드타임을 10분에서 2분으로 줄였고, 반복 QA 시간도 3시간에서 1시간으로 단축했습니다. PC·모바일 웹 모두에서 성능과 팀 생산성을 수치로 개선해 온 경험을, 쿠팡이츠 웹 플랫폼의 효율적인 아키텍처 구축에 그대로 이어가고 싶습니다.

## 크로스팀 협업과 팀 품질·가이드 관점의 일하기

웹 기능은 프론트엔드 혼자 완성되지 않는다고 생각합니다. AI 건강검진 챗봇을 실서비스로 고도화할 때 저는 AI 개발자와 API 응답 형식·스트리밍·오류 정책을 조율했고, 기획·디자인·백엔드·운영 조직과 응답 정책·배포 프로세스·오류 대응 기준을 함께 맞췄습니다. 프론트 전용 데이터 집계·프록시 BFF REST API를 Node.js·Express로 신규 구축해, 여러 백엔드 데이터를 프론트가 받아 쓰기 좋게 단일 계층으로 정리하기도 했습니다. 여러 팀과 다중 우선순위 업무를 WBS·ETA로 관리하며 조율해 온 방식은, Product·UX·Backend·Mobile 팀과 협업해 프로젝트를 이끄는 쿠팡이츠 웹 플랫폼의 일하는 방식과 잘 맞는다고 생각합니다.

Staff 관점에서 제가 강점을 두는 부분은 팀 전체의 품질·생산성 기준을 만드는 일입니다. AI 생성 코드의 컨텍스트 관리·금지 패턴·보안 위험·검증 절차를 FE AX SOP로 문서화했고, 개발 세미나 12회와 기술 문서 48건을 통해 배운 것을 팀에 공유했습니다. 답변 화면 정상 출력률은 400건 발화 검증 기준으로 100%를 확보했습니다. 다른 시니어 엔지니어를 직접 리드한 경력이 앞으로의 과제라면, 저는 반복 QA·배포·컴포넌트 개발을 자동화하고 개발 기준을 문서로 남겨 팀의 생산성과 품질을 끌어올려 온 경험으로 그 역할에 다가가겠습니다.

## E-commerce 경험과 O2O 확장 의지

저는 한국미스미 글로벌 B2B 커머스에서 상품·주문 흐름과 성능·SEO·다국어·모니터링을 다루며 커머스 도메인의 사용자 경험과 트래픽·품질 문제를 직접 경험했습니다. 배달 O2O 서비스를 직접 개발한 경험은 아니지만, 많은 사용자가 동시에 쓰는 커머스 웹에서 성능과 안정성을 지켜 온 경험은 쿠팡이츠의 새로운 고객 경험 웹 기능을 만드는 일에도 이어질 수 있다고 생각합니다. 입사 후에는 유연하고 효율적인 PC·모바일 웹 아키텍처를 설계하고, 컴포넌트화·모듈화와 자동화로 팀의 개발 생산성과 웹 제품 품질을 함께 끌어올리는 데 기여하고 싶습니다.
