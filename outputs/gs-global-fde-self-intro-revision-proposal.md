## [직무수행 역량 및 자세] 3번 — 최우선 축소 제안

### before (현행, 4문단)

> 여러 백엔드 데이터를 연결하기 위해 **Node.js 기반 데이터 집계·중계 API를 신규 구축**했고, 수동 배포는 Jenkins와 **Docker Blue-Green 무중단 배포**로 전환해 배포 시간을 **10분에서 2분으로 줄였습니다.**
>
> 삼성물산 프로젝트에서도 렌더링 생명주기 분리와 Oracle SQL 필터링·정렬 튜닝·DB 인덱싱·DTO 투영을 양단에 적용해 대용량 데이터 화면의 렌더링을 **2.5초에서 1초대**, 모바일 검색을 **5초에서 1초로 단축**했습니다.

>
> 삼성물산 프로젝트에서는 느리다는 요청을 추정으로 처리하지 않고 API 응답 시점과 화면 노출 시점을 나눠 측정해 병목을 특정한 뒤, 프론트엔드와 백엔드 양단에 개선을 적용해 대용량 데이터 화면의 렌더링을 **2.5초에서 1초대**, 모바일 검색을 **5초에서 1초로 단축**했습니다.

- 1·2문단을 하나로 합치고 **스택 나열을 판단 서술로 교체**했다. "jQuery·Thymeleaf·Spring Boot·MySQL", "MySQL 데이터 모델부터 Spring Boot 서버, REST API, Web·Admin 화면", "Node.js 기반 데이터 집계·중계 API"는 **제2부 3) 실행 불릿 1~4와 전면 중복**이다.
