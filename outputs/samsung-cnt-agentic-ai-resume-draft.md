## 지원동기 및 입사 후 Vision

저는 내담씨앤씨 SI 소속으로 삼성물산 건설부문 현장 앱을 만들어 출시·운영하며 장비·인력 데이터를 조회·관리하는 현장 사용자의 흐름을 다뤘고, 대웅제약에서는 AI 챗봇의 LLM 릴레이·에이전트 서버 API와 MCP 서버를 개발했습니다. 건설부문 현장 앱의 사용자와 데이터를 아는 개발자가 그 Application과 연동되는 Agentic AI 서비스를 설계·개발할 수 있다고 생각해 지원했습니다.

AI코치에서는 AI 서버와 다른 서비스 사이의 SSE 이벤트 형식·응답 형식·오류 처리를 먼저 맞췄고, LLM 호출 오류·타임아웃 때의 응답 방식도 정했습니다. 입사 후에도 연동 대상 Application의 조회 흐름과 AI 서비스의 응답 형식·오류 처리를 먼저 맞추는 것부터 시작하겠습니다.

대웅제약에서 AI에 제공할 작업 정보·금지 패턴·검증 절차를 개발 표준 문서로 정리해 10명 팀이 활용했고, 사내 MCP 서버를 Claude Code·Codex에 연동했습니다. AI코치 차기 버전은 서브에이전트 18개로 구성된 멀티 에이전트 서버이며, 저는 여기서 에이전트별 프롬프트·컨텍스트 작성과 SSE 이벤트 연동을 맡고 있습니다. 입사 후에도 에이전트가 호출할 Application 기능·금지 동작·검증 절차를 먼저 문서로 정하고 MCP로 연결하겠습니다.

개발 후에는 E2E 테스트를 배포 조건으로 두고 LLM 응답은 회귀 검수로 확인하겠습니다. 운영에서는 Linux 서버에서 배포·재기동과 로그 확인을 직접 수행하고, PostHog 오류를 GPT-4o로 분석하는 보고서 자동화 경험을 살려 오류 원인부터 확인해 수정 순서를 정하겠습니다.
