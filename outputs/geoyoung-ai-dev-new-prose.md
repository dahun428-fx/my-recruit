- [자기소개서] **1. AI 소프트웨어를 설계하고 구현합니다**
- [자기소개서] 2025년 대웅 AI추진팀에서 AI 건강검진 챗봇을 개발자 5명과 함께 만들었습니다. **Python 기반 LLM API 연동 릴레이 서버·API 구축에 참여**했고, 기획자와 MVP 범위를 정하고 응답 형식·스트리밍·오류 정책을 먼저 합의한 뒤 SSE 스트리밍, 재시도·재생성, 오류 복구 구조까지 구현해 **10주 만에 임직원 3,493명이 쓰는 실서비스로 전환**했습니다. 2026년에는 이 서비스를 서브에이전트 18개를 오케스트레이터가 의도 분류·라우팅·병렬 실행·종합하는 v2 멀티 에이전트 서버로 전환하는 연구·개발에 **오케스트레이션 설계 논의와 에이전트 프롬프트·컨텍스트 엔지니어링, 검증 하네스로 참여**했습니다. 프롬프트와 컨텍스트를 어떤 순서로 구성해 응답을 어떤 형식으로 내보낼지를 LLM·서버 개발자와 맞춰 가며, 애플리케이션을 둘러싼 프롬프트·컨텍스트·검증 하네스를 맡았습니다.

- [자기소개서] **2. AI 도입의 병목은 생성 속도가 아니라 신뢰 기준입니다**
- [자기소개서] AI 코딩 에이전트를 도입하자 코드를 만드는 속도보다 만들어진 코드를 무엇으로 믿을지가 병목이 됐습니다. 그래서 발화·LLM 응답·빌드·배포 검증을 자동 실행되는 하네스로 묶고 E2E를 배포 필수 게이트로 편입했습니다. 사내 문서 검색과 테스트 도구를 호출하는 **MCP 서버를 직접 개발·수정해 Claude Code·Codex에 연동**했고, 운영 에러를 GPT-4o가 소스 코드와 함께 분석해 리포트하는 파이프라인을 만들었으며, Figma MCP와 SKILL.md로 개발 맥락을 자산화해 기획 → 에이전트 → Storybook → 테스트로 이어지는 흐름을 만드는 방향으로 추진하고 있습니다.
