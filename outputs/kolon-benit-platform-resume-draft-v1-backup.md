### 팀이 반복해서 사용할 수 있는 기준을 만듭니다

대웅제약에서 AI 코딩 에이전트 도입 후 팀원마다 활용 방식과 검증 수준이 달랐습니다. 이를 해결하기 위해 컨텍스트 관리, 금지 패턴, 보안 위험, 검증 절차를 **프론트엔드 AI 활용 개발 표준으로 설계**했고 사내 공식 문서로 채택됐습니다. 외부에서 얻은 지식도 개발 세미나 12회와 기술 문서 48건으로 축적해 **10명 팀 전원이 동일한 방식으로 개발·검증하도록 정착시켰습니다.**

반면 결과물을 충분히 검증하려는 성향 때문에 확인 작업에 시간이 많이 들 때가 있었습니다. 이를 개인의 습관이 아닌 프로세스 문제로 보고 **LLM 응답과 UI를 자동 검증하는 회귀평가 도구를 직접 제작하고 E2E 검증을 배포 게이트에 적용했습니다.** 그 결과 반복 QA 시간을 **3시간에서 30분으로 단축**했습니다.

### 레거시부터 API·SQL·배포까지 연결하는 실행력

비즈36.5에서는 jQuery·Thymeleaf·Spring Boot·MySQL 기반 레거시를 분석하고 **React 화면 단위 점진 전환 구조를 설계했습니다.** 신규 기능 3건은 MySQL 데이터 모델부터 Spring Boot 서버, REST API, Web·Admin 화면까지 직접 개발했습니다.

여러 백엔드 데이터를 연결하기 위해 **Node.js 기반 데이터 집계·중계 API를 신규 구축**했고, 수동 배포는 Jenkins와 **Docker Blue-Green 무중단 배포**로 전환해 배포 시간을 **10분에서 2분으로 줄였습니다.**

삼성물산 프로젝트에서도 렌더링 생명주기 분리와 Oracle SQL 필터링·정렬 튜닝·DB 인덱싱·DTO 투영을 양단에 적용해 대용량 데이터 화면의 렌더링을 **2.5초에서 1초대**, 모바일 검색을 **5초에서 1초로 단축**했습니다.

AI 건강검진 챗봇에서는 기획자와 MVP를 정의하고 PoC를 거쳐 **10주 내 실서비스로 전환해 임직원 3,493명 규모로 운영했습니다.** AI 개발자와 응답 형식, SSE 스트리밍, 오류 정책을 먼저 합의하고 중지·재시도·재생성, 상담 이력, Markdown·표·링크 렌더링과 오류 복구 구조를 구현했습니다.
