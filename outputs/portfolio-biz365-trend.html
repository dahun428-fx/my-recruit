Project 01 / AI Healthcare Coach

나만의 건강 AI코치

건강검진 결과를 사용자가 이해하고 질문할 수 있는 AI 상담 서비스로 전환했습니다.

Healthcare AI Service

서비스 소개

나만의 건강 AI코치는 사용자의 건강검진 결과를 기반으로 건강 상태를 설명하고, 궁금한 내용을 대화형으로 안내하는 AI 건강 상담 서비스입니다. 단순히 검진 수치를 보여주는 것이 아니라 사용자가 자신의 건강 상태를 이해하고 다음 행동을 결정할 수 있도록 돕는 것이 핵심입니다.

주요 기능

  • 건강검진 결과 기반 AI 상담
  • 이상소견 및 검사 항목 설명
  • 만성질환 분석과 건강관리 방법 추천
  • 병원 검색 및 관련 질문 안내

개발사항

  • 검진 결과 기반 AI 챗봇 화면을 구성하고, 이상소견 상세·만성질환 분석·검사 항목 설명·건강관리 추천을 선택해 질문할 수 있는 흐름으로 개발했습니다.
  • AI 답변이 한 번에 늦게 표시되지 않도록 SSE 기반 스트리밍 응답을 적용하고, 답변이 순차적으로 출력되는 상담 경험을 구현했습니다.
  • AI API 응답의 텍스트, 목록, 버튼, 관련 질문을 화면에서 안정적으로 표시할 수 있도록 응답 처리 규칙과 렌더링 흐름을 정리했습니다.
  • 모바일, 태블릿, 데스크톱 환경에서 동일한 상담 흐름을 사용할 수 있도록 반응형 화면을 구성했습니다.
  • 반복 질문, 응답 실패, 빈 결과, 예외 상황에 대한 화면 흐름을 정리하고 POC 환경에서 검증했습니다.

핵심 기여

AI 모델의 답변을 단순히 출력하는 화면이 아니라, 검진 결과를 이해하고 질문할 수 있는 상담 경험으로 구성했습니다. SSE 기반 스트리밍 응답, AI API 응답 규격 조율, 검진 결과 해석 흐름 구성, 예외 케이스 검증을 통해 실제 사용 가능한 AI 건강 상담 서비스로 개선했습니다.

Project 02 / B2B Healthcare Platform

비즈 36.5

기업 건강관리 기능을 고객사별로 확장 가능한 B2B 플랫폼 구조로 개선했습니다.

B2B Platform

서비스 소개

비즈 36.5는 기업 임직원의 건강검진과 건강관리를 통합 제공하는 B2B 건강관리 플랫폼입니다. 임직원은 하나의 플랫폼에서 검진 예약, 검진 결과 확인, 건강제도 확인, 사후관리, 건강관리 서비스를 이용할 수 있습니다.

이 서비스의 핵심은 고객사마다 다른 건강검진 제도와 운영 조건을 하나의 플랫폼 안에서 처리하는 것입니다.

주요 기능

  • 임직원 건강검진 예약 및 결과 확인
  • 건강제도, 지원금, 사후관리 안내
  • 고객사별 브랜딩 및 메뉴 구성
  • 검진 결과 추이분석 및 AI코치 연동

개발사항

  • 검진예약, 검진결과, 건강제도, 건강관리, 사후관리, 공지·고객센터 기능을 하나의 플랫폼 흐름으로 재구성했습니다.
  • 고객사별 CI, 로고, 메뉴, 탭, 제도 조건, 노출 항목을 반영할 수 있도록 화면과 설정 구조를 정리했습니다.
  • 108페이지 / 82화면 규모의 플랫폼 개편 과정에서 반복되는 화면 요소를 재사용 가능한 컴포넌트로 정리했습니다.
  • 검진 결과 확인 이후 주요 건강지표의 변화 추이를 확인하고, 나만의 건강 AI코치로 이동할 수 있는 진입 흐름을 연결했습니다.
  • 주요 사용자 흐름과 화면 변경 영향 범위를 기준으로 확인 절차를 정리해 운영 대응 기준을 명확히 했습니다.

핵심 기여

고객사마다 달라지는 건강관리 제도와 운영 조건을 반복 가능한 B2B 플랫폼 구조로 정리했습니다. 단순 화면 개편이 아니라 고객사별 브랜딩, 메뉴 노출, 제도 조건, 검진 결과 추이분석, AI코치 진입 흐름을 하나의 서비스 구조 안에서 관리할 수 있도록 개선했습니다.

Project 03 / Health Data Report Service

바이오에이지

검진 데이터를 생체나이 리포트로 안정 생성하고 운영할 수 있도록 개선했습니다.

Health Data Report

서비스 소개

바이오에이지는 건강검진 데이터를 기반으로 사용자의 생체나이와 질병 위험도를 분석해 리포트로 제공하는 서비스입니다. 단순한 검진 결과표가 아니라 사용자의 실제 건강 상태를 나이와 위험도 관점에서 이해할 수 있도록 돕습니다.

주요 기능

  • 생체나이 및 기능별 나이 분석
  • 질병 위험도와 노화 요인 분석
  • 건강 개선 가이드 제공
  • PDF 또는 리포트 형태 결과 제공

개발사항

  • 생체나이, 기능별 나이, 질병 위험도, 노화 요인, 개선 가이드를 사용자가 이해할 수 있는 리포트 화면으로 구성했습니다.
  • 외주 의존도가 있던 리포트 디자인·퍼블리싱 작업을 내부에서 수정·반영할 수 있도록 개발 구조를 정리했습니다.
  • 기존 고객이 새로운 리포트 구조로 전환되는 과정에서 화면과 리포트 결과가 안정적으로 제공되도록 수정 및 확인했습니다.
  • 리포트 누락 이슈 발생 시 DB, API, PDF 생성 흐름을 따라 데이터 전달 과정을 확인하고 문제 범위를 좁혔습니다.
  • 검진 데이터가 리포트로 생성되는 과정에서 누락이나 표시 오류가 발생하지 않도록 화면·데이터·생성 흐름을 함께 확인했습니다.

핵심 기여

검진 데이터가 최종 리포트로 생성되는 흐름을 이해하고, 운영 이슈 발생 시 원인을 추적할 수 있는 구조로 개선했습니다. 단순 리포트 제작이 아니라 DB, API, PDF 생성 흐름을 확인하며 문제 범위를 좁혔고, 고객 전환과 리포트 제작 과정을 안정화했습니다.
