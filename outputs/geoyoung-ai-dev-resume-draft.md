## 자기소개서

### [본인 소개 및 성격 특장점]

웹 화면부터 서버·DB·배포까지 전 구간을 개발해 온 6년차 풀스택 개발자입니다. 빅데이터분석기사 준비와 KT AICE 과정으로 ML·딥러닝을 학습하고 개인 프로토타입으로 Qdrant RAG와 FastMCP 에이전트 서버를 직접 만들어 본 뒤, **대웅 AI추진팀에서 개발자 5명과 실제 AI 소프트웨어를 설계·구현**했습니다.

AI 건강검진 챗봇에서는 **Python 기반 LLM API 연동 릴레이 서버·API 구축에 참여**하고 프롬프트·컨텍스트 구성과 검증 하네스를 담당했습니다. 응답 형식·스트리밍·오류 정책을 AI 개발자와 먼저 합의하고 오류를 4유형으로 나눠 복구까지 설계해 **10주 만에 임직원 3,493명이 쓰는 실서비스로 전환**했습니다. 2026년에는 같은 서비스를 서브에이전트 18개 구조로 전환하는 연구에 **오케스트레이션 설계 논의와 프롬프트·컨텍스트 엔지니어링, 검증 하네스로 참여**했고, RAG·VectorDB 구현은 LLM 개발자가 담당했습니다.

**성격 특장점은 확인되지 않은 것을 그대로 넘기지 못한다는 점입니다.** 만들기 전에 무엇으로 검증할지를 먼저 정하는데, AI 제품에서는 이 성향이 강점으로 작동했습니다. 응답을 어디까지 보장하고 어떤 오류를 어떻게 복구할지 먼저 합의한 뒤에야 화면에 답이 안정적으로 떴습니다.

**같은 성향 때문에 확인 작업에 시간이 많이 드는 것이 약점이었습니다.** 이를 개인의 습관이 아니라 프로세스의 문제로 보고 LLM 응답과 UI를 자동 검증하는 회귀평가 도구를 직접 만들어 **반복 QA 시간을 3시간에서 30분으로 줄였습니다.** 꼼꼼함을 사람의 노력이 아니라 팀이 쓰는 도구로 바꾸는 편입니다.

**3. 커뮤니케이션 — 비개발 직군이 스스로 쓸 수 있는 형태로 만듭니다**

AI코치의 고객사별 기능 차등 과금 요구를 화면을 새로 만드는 문제가 아니라 **하나의 서비스로 여러 상품을 운영하는 문제로 다시 정의**했습니다. 테마·기능 노출을 설정값으로 다루도록 바꿔 운영 담당자가 직접 운영하게 했고, 기획·운영팀에는 **요구사항·화면설계서 작성 가이드를 만들어 교육**했습니다. 앞선 프로젝트에서는 일본 본사 개발자와 **일본어로 직접 소통**하며 전 지사 아키텍처 통일의 한국 파트를 수행했습니다.
