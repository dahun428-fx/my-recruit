+내담씨앤씨 SI 프로젝트(삼성물산 건설부문·한국미스미)에서 서로 다른 요구사항과 기술 환경에 맞춰 개발해 온 경험은, IT 서비스·솔루션 기업의 다양한 고객 환경에서 요구사항을 파악하고 개발 방향을 맞추는 데 도움이 될 것이라고 생각합니다. 여기에 자사 서비스에서 익힌 배포·운영 자동화와 AI 개발 도구 활용 경험을 더해, GS네오텍 플랫폼개발(풀스택) 포지션에서 플랫폼을 개발부터 운영까지 맡고 싶습니다.
+입사 후에는 운영 중인 플랫폼의 코드 구조와 데이터 처리 방식, 배포 방식을 먼저 익히고, 실제로 발생하는 오류와 반복 요청부터 처리하겠습니다. 조회가 느린 화면은 API 응답 시간과 화면 표시 시간을 나눠 측정한 뒤 쿼리·인덱스·응답 구조를 점검하고, 배포와 운영 확인에서 사람이 반복하던 작업은 E2E 테스트와 배포 게이트로 옮기겠습니다. 운영 중인 플랫폼에 기능을 더할 때도 기존 데이터 구조에 영향을 주지 않는 방식부터 검토하고, 단위·통합 테스트로 검증한 뒤 배포하겠습니다.
+중장기적으로는 클라우드 기반 플랫폼을 개발하면서 Claude Code·Codex 같은 AI 개발 도구를 팀의 개발·검증 절차에 녹여, 개발 생산성을 이끄는 풀스택 개발자로 성장하고 싶습니다. AI가 생성한 코드도 테스트와 코드 리뷰를 통과한 뒤 배포되도록 프로젝트에 맞는 기준을 마련하겠습니다.
