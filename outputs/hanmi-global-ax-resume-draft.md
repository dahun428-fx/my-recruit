그리고 같은 확인 작업이 반복되면 AI를 활용하여 시간을 감축하고 생산성을 높일 방법을 찾는, 효율성과 생산성을 중요시합니다. 챗봇 응답과 UI를 검증하는 도구를 직접 만들고 배포 전에 자동으로 실행하도록 연결해, 반복 QA에 걸리는 시간을 3시간에서 30분으로 줄였습니다.

Figma MCP를 도입해 디자인 산출물 기반 신규 기능 개발 기간을 1주에서 1일로 단축했으며, 데이터 시각화 공통 로직을 표준화해 신규 차트 개발 시간을 1시간에서 10분으로 줄였습니다. 또한 자동 테스트를 58건에서 2,318건으로 확대하고, Storybook에 93개 컴포넌트·258개 UI 상태를 구성해 화면 검증 체계를 강화했으며 이 과정에서 버그 64건을 개선했습니다. AI를 단순 코드 생성 도구로 활용하는 데 그치지 않고 기획·개발·검증 과정에 연결함으로써 반복 구현과 확인 작업을 자동화하고, 개발자가 설계와 결과 판단에 집중할 수 있는 개발 프로세스를 구축했습니다.

**2. AI 기술 탐구 및 실무 적용 역량**

새로운 AI 기술은 직접 구현하며 동작 원리와 한계를 검증하고 실무 적용 가능성을 판단합니다. AI 챗봇 개발 과정에서 Qdrant 기반 RAG와 FastMCP 기반 에이전트 서버 구현을 위해 관련 라이브러리·기술 문서·논문을 검토하고 실제 서비스에 적용했으며, 프롬프트·컨텍스트 구성과 응답 검증 도구 개발을 담당했습니다. 이후 18개 서브에이전트로 구성된 차기 버전 연구에서도 에이전트 간 실행·연결 구조의 설계 논의와 개발에 참여했습니다.

LLM을 사내 개발 환경과 연결하는 도구도 직접 구현했습니다. 문서 검색용 및 테스트 도구 호출용 MCP 서버 2종을 개발·개선해 Claude Code와 Codex에 연동했으며, OpenAI API와 TypeScript를 활용해 PostHog 오류 데이터와 GitLab 소스 코드를 기반으로 GPT-4o가 오류 원인을 분석하고 보고서를 생성하는 자동화 기능을 구축했습니다. 새로운 기술을 학습하는 데 그치지 않고 실제 서비스와 개발 업무에 적용한 뒤, 활용 방법과 검증 절차를 표준화해 팀에 공유하고 있습니다.

**3. 업무 프로세스 분석 및 요구사항 정의 역량**

건강관리실 동의서 업무를 보건 담당자·기획·운영 부서와 함께 분석해, 종이와 엑셀로 처리하던 업무 절차를 시스템 요구사항으로 구체화했습니다. 동의서 발송·회수, 대리 등록, 철회, 담당자별 권한 분리까지 업무 범위를 정의하고 우선순위를 조율해 핵심 기능 4건을 건강검진 플랫폼에 적용했습니다.

검진 진행현황 기능은 현장 보건관리자의 피드백을 바탕으로 수검 판정 기준을 정립하고, 기존 회원관리 화면을 재사용하는 방향으로 설계해 신규 개발 범위를 최소화했습니다. 직군별로 요구사항이 다를 때는 실제 업무 사례와 변경에 따른 영향을 함께 검토하며 기능 범위와 처리 기준을 합의했습니다. 이를 통해 현업의 업무 방식을 단순히 시스템으로 옮기는 데 그치지 않고, 실제 운영 흐름에 맞는 요구사항을 정의하고 개발 범위를 최적화했습니다.

### [지원동기 및 입사 후 포부]

한미글로벌 AX실에서 사내 AI 활용을 위한 웹 서비스와 생산성 애플리케이션을 개발한다는 점에 관심을 갖고 지원했습니다. 저는 기존 웹 서비스를 개선하는 일에서 시작해 AI 챗봇과 사내 개발 도구를 만드는 일까지 경험을 넓혀 왔습니다. 화면과 API를 개발하고 운영해 온 경험을 바탕으로, 구성원들이 업무에서 편하게 사용할 수 있는 AI 서비스를 만들고 싶습니다.

삼성물산 건설부문 프로젝트에서는 현장 장비와 인력 데이터를 조회·관리하는 앱과 대시보드를 개발했습니다. 이후 대웅제약과 다나아데이터에서는 건강검진 플랫폼과 AI 챗봇을 개발·운영하고, MCP 서버와 LLM API를 활용한 업무 도구를 구현했습니다. 건설 현장의 데이터를 다뤄 본 경험과 AI 서비스 개발 경험이 한미글로벌의 업무와 기존 시스템을 이해하는 데 도움이 될 것이라고 생각합니다.

입사 후에는 진행 중인 프로젝트의 코드와 데이터 흐름, 배포 방식을 먼저 익히겠습니다. 필요한 기능과 현재 발생하는 오류를 확인해 기존 서비스 개선부터 맡고, 현업의 의견을 받아 사용하기 불편한 부분을 줄이겠습니다. 새로운 AI 기능도 기존 화면과 API에 어떻게 연결할지 살피며 개발하겠습니다.

AI 개발 도구는 적극적으로 활용하되, 변경한 코드가 의도대로 동작하는지 직접 확인하겠습니다. 제가 경험한 응답 검증과 테스트 자동화 방법을 프로젝트에 맞게 적용하고, 배포 후에도 로그와 사용자 피드백을 보며 수정하겠습니다. 만든 기능이 실제 업무에 쓰이고 안정적으로 운영될 때까지 책임지고 일하겠습니다.
