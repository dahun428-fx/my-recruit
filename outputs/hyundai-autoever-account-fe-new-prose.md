## 플래그 (소유자·reviewer 확인 필요)

- **F1 총 경력**: 2020.10 → 2026.10(오늘 2026-10-29) 연속 재직, base와 같은 "월 차이" 산식(2020.10→2026.07 = 5년 9개월)으로 **72개월 = 총 6년**. 시작 월을 포함해 세면 6년 1개월. 연차는 만 6년 경과로 "7년차"에 해당할 수 있어 요약에서 "N년차" 표기를 피하고 "6년 경력"으로 썼다.
- **F2 Vitest 약 2,600케이스 삭제**: base 핵심 성과 ④·챗봇 성과에 남아 있으나 은행 EXP-01 [제외 결정](2026-08-12 소유자)이 "어떤 문면에도 사용하지 않는다"로 base(07-27)보다 나중에 결정 → 삭제.
- **F3 needs_scope 신규 지표 3묶음**: 2026-10-29 소유자 사실 확인을 근거로 사용(A33·A46·A73). registry 상태는 아직 needs_scope — 최상위 에이전트의 상태 갱신 필요.
- **F4 품질 Gate·QA 3시간→30분 귀속 이동**: 은행 EXP-03(2026.01~06)은 대웅 기간, 소유자 최신 잡코리아 경력기술서는 다나아(2026.06~) 아래에 둔다. 브리프("다나아 Release Flow·Playwright 품질 Gate")와 잡코리아를 따라 **다나아 1번**에 배치하고, 대웅 4번에서는 Gate 구절을 빼 이중 서술을 막았다. 24 시나리오 30분→5분(대웅 4번)과는 다른 항목이라 연쇄되지 않는다.
- **F5 S-03(MUST) 충돌**: "UI 수정 범위 약 70%·리드타임 약 50%"(A46)와 "신규 기능 개발 약 50%"(A34)는 전후값이 없어 퍼센트 단독이다. 미스미 50%처럼 소유자 예외 결정이 필요하다 — 미승인 시 A46은 "UI 수정 범위·커스터마이징 리드타임 축소"로 정성화, A34는 "빌드 5분 → 1분"만 남기는 안을 제안한다.
- **F6 은행 미적재 base 사실**: RN 단일 구조 통합(50%·5분→1분)·사전문진 개편·커버리지 54%→84%는 base(소유자 확정)·base 자소서·DH 100/125/126행에만 있고 `experience-bank.md`에 없다 → archivist 적재 권장.
