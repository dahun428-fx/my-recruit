# Process Rules Archive (retired 규칙 보관소)

`process-rules.md`에서 retire된 규칙을 보관한다. 이 파일은 `CLAUDE.md`에
import되지 않으므로 컨텍스트 비용이 없다. 옮기기 전에 헤딩의 상태를
`retired`로 바꾸고 항목 끝에 `- 해제: YYYY-MM-DD 이유` 한 줄을 추가한 뒤,
항목 전체를 그대로 이곳으로 이동한다. ID(`P-NN`)는 재사용하지 않으므로 새
ID를 매길 때 이 파일의 마지막 번호까지 확인한다. 재활성화하려면 항목을
`process-rules.md`로 되돌리고 상태를 `probation`부터 다시 시작한다.
