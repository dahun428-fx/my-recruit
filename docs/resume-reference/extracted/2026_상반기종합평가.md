2026년 상반기에는 AI 헬스케어 사업 매출 11.8억 원 달성 및 수익 구조 안정화를 목표로, 나만의 건강 AI코치·비즈 36.5·바이오에이지의 서비스 품질과 확장 기반을 고도화하였다. AI코치 답변 출력 시간 10초 → 4초로 60% 단축, 답변 화면 품질 정상 출력률 100%(400건 기준)를 달성했으며, Base-Theme FE 구축을 통해 신규 챗봇 개발 기간을 10주 → 2주로 80% 단축 가능한 구조를 마련하였다.

기업검진 B2B 확장 측면에서는 비즈 36.5 임직원 통합 플랫폼 전환을 9주 내 완료하고, 108개 페이지·82개 화면을 전면 개편하였다. 또한 건강 TF 협업 기반 신규 기능 3건을 개발하고, 고객사별 브랜딩 변경 요청에 1주 내 대응 가능한 SaaS형 구조를 마련하여 외부 기업검진 고객사에 반복 적용 가능한 B2B 플랫폼 기반을 구축하였다.

운영 안정성 측면에서는 600여 건의 E2E 회귀 검증 자동화로 QA 소요 시간을 3시간 → 1시간으로 60% 단축하고, 운영 데이터 확인 절차를 3단계 수작업에서 1단계 자동화 대시보드로 전환하였다. 또한 AI코치 반복 컴포넌트 개발 시간을 90분 → 15분으로 약 83% 단축하여 QA·운영·개발 전반의 수작업 의존도를 낮추고 업무 생산성을 개선하였다.

이 과정에서 월별피드백과 상사 피드백을 통해 AI 챗봇 개발의 개별 구축 방식이 리드타임과 품질 편차를 키울 수 있다는 Gap을 인식하고, 이를 보일러 플랫폼 구축과 FE 확장 구조로 연결하였다. 또한 인수인계서를 통해 바이오에이지의 전략적 중요도와 운영 리스크를 사전에 파악하고, 직무급 관점에서 대시보드·운영 도구·AI 활용 SOP를 작성하고 조직이 반복 활용할 수 있는 업무 자산으로 전환하였다.

종합적으로 본인은 2026년 상반기 동안 AI코치 실서비스 품질 안정화, 신규 챗봇 확장 구조 마련, 비즈 36.5 B2B 플랫폼 전환, 운영 자동화 및 FE AX 개발 기준 정착에 기여하였다. 이를 통해 단순 기능 개발을 넘어 서비스 상품화·운영 안정성·조직 자산화로 성과를 확장하며, 대웅의 핵심가치인 자율과 성장이 실제 업무 성과로 이어지도록 기여하였다.
